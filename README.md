# 🐔 El Polo Loco

## 📌 Description
El Polo Loco is a fun jump-and-run game built using an object-oriented approach. Help Pepe collect coins and tabasco salsa while fighting against crazy hens.

## 🚀 Features
- Jump & run gameplay
- Object-oriented programming structure
- Collect coins and power-ups
- Throw tabasco bottles to defeat enemies
- Enemy AI (crazy hens)
- Sound effects and animations

## 🛠️ Technologies
- HTML
- CSS
- JavaScript

## ▶️ Live Demo
[Play the game](https://elpololoco.kevin-breiter.de/)

## 🎮 How to Play
- Move left/right
- Jump over obstacles
- Collect coins and salsa bottles
- Throw bottles to defeat enemies
- Survive and win the game!
